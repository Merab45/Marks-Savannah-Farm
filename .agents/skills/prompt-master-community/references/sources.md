# Sources and Research Notes

Research date: 2026-08-12.

## Primary guidance

- [OpenAI GPT-5.6 prompting guidance](https://developers.openai.com/api/docs/guides/prompt-guidance-gpt-5p6): outcome-first prompts, lean instructions, explicit autonomy, relevant tools, evidence, and evaluation.
- [OpenAI model guidance](https://developers.openai.com/api/docs/guides/latest-model): prompt simplification and evaluation of success, completeness, evidence, tokens, latency, and cost.
- [openai/skills](https://github.com/openai/skills): reference for portable skill structure and community contribution norms.

## Community references

- [nidhinjs/prompt-master](https://github.com/nidhinjs/prompt-master): useful ideas include intent extraction, compact output, secret handling, and progressive references. This project does not copy its large multi-tool catalog or its unverified model claims.
- [treylom/prompt-engineering-skills](https://github.com/treylom/prompt-engineering-skills): useful example of model-specific reference routing. This project keeps the active skill small and avoids version-specific rules unless sourced from current official documentation.
- [k-vaca/prompt-engineering-skill](https://github.com/k-vaca/prompt-engineering-skill): a research-grounded community reference. It is treated as a hypothesis source, not authority.

## Maintenance rule

For an OpenAI/Codex behavior claim, verify the current official source before merging. For a community claim, add an eval case or label it as a hypothesis.
